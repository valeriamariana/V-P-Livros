# V-P-Livros
Uma plataforma de biblioteca virtual criada para conectar leitores, livros e escritores. O aplicativo permite organizar leituras, acompanhar o progresso, receber recomendações personalizadas e avaliar obras. Além disso, escritores podem publicar e divulgar seus livros, tornando a experiência de leitura mais organizada, interativa e acessível.
